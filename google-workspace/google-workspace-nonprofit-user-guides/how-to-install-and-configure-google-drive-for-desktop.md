# How to Install and Configure Google Drive for Desktop

Drive for desktop puts Google Drive in File Explorer (Windows) or Finder (Mac) so you can open and save files like any other folder. Use your **work Google Workspace** account, not a personal Gmail account.

Download: [Google Drive for desktop](https://www.google.com/drive/download/)

## Install

1. Open the [download page](https://www.google.com/drive/download/) and choose **Windows** or **Mac**.
2. Run the installer:
   * Windows: `GoogleDriveSetup.exe`
   * Mac: `GoogleDrive.dmg`
3. Follow the on-screen prompts, then open **Google Drive**.

## Sign in

1. Click **Get started**, then **Sign in**.
2. Sign in with your nonprofit Google Workspace email (the same account you use for Gmail at work).
3. Complete MFA if prompted.
4. Confirm Drive is running:
   * Windows: Google Drive icon in the taskbar (bottom right; click the **^** arrow if it is hidden)
   * Mac: Google Drive icon in the menu bar (top right)

## Configure (stream vs mirror)

In the Drive icon menu, open **Settings** (gear) → **Preferences**.

* **Stream files** (recommended for most people) — files stay in the cloud and download when you open them. Uses little disk space.
* **Mirror files** — a full copy is stored on this computer. Use this only if you need everything offline and have enough disk space.

Google’s explanation: [Stream files or mirror files](https://support.google.com/drive/answer/7636029).

Then open **Google Drive** in File Explorer or Finder. You should see **My Drive** and, if your org uses them, **Shared drives**.

{% hint style="info" %}
Syncing is not a backup. Accidental deletes and ransomware still sync. See [Backup Software for Nonprofits](../../tech-recommendations/it-management-and-security-solutions/backup-software-for-nonprofits.md).
{% endhint %}
