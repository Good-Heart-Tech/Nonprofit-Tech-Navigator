# How to Use Separate Chrome / Edge Profiles for Work and Personal

If you use one computer for **nonprofit work** and **personal** browsing, keep them in **separate browser profiles**—not one mixed window where Gmail, Microsoft 365, and your personal accounts fight for the same cookies and logins.

{% hint style="info" %}
**Profiles vs. private windows:** Incognito / InPrivate is fine for a quick test or one-off sign-in. For day-to-day work, use a dedicated **Work** profile. See [How to Use Incognito / InPrivate Browsing](how-to-use-incognito-inprivate-browsing.md).
{% endhint %}

## Why use separate profiles?

| With one mixed browser | With work + personal profiles |
| --- | --- |
| Easy to post or email from the wrong account | Work sites stay signed in only under **Work** |
| Work and personal passwords, history, and extensions overlap | Bookmarks, extensions, and saved passwords are isolated |
| “Wrong account” bugs on Google Drive, SharePoint, and SSO | Each profile has its own icon, name, and color so you can tell them apart |

Use **Work** for your org Google or Microsoft account, donor tools, and anything your nonprofit expects you to use on the job. Use **Personal** for your own email, shopping, and social media.

---

## Google Chrome

1. Open Chrome.
2. Click your **profile picture** (top right). If you only see one person icon, click it.
3. Choose **Add** (or **Add Chrome profile**).
4. Name the profile (for example **Work** or your organization name). Pick a **color** or theme so the window is easy to spot.
5. When Chrome asks you to sign in, sign in with your **work** Google account for the work profile—or skip sign-in for a local-only personal profile.
6. Repeat **Add** to create a **Personal** profile with your personal Google account (or no account).

**Switch profiles:** Click the profile icon → select **Work** or **Personal**. Each opens in its own window.

**Tip:** Right-click the Chrome icon on the taskbar (Windows) or Dock (Mac) and pin the profile you use most, or open Chrome from the profile menu so the right one launches by default.

[Google: Share Chrome with others / multiple profiles](https://support.google.com/chrome/answer/2364824)

## Microsoft Edge

Edge uses the same idea: each profile has its own Microsoft (or other) sign-in, favorites, and extensions.

1. Open Edge.
2. Click your **profile picture** (top left on Windows, or top right depending on layout).
3. Select **Set up new personal profile** or **Add profile**.
4. Name it **Work** or **Personal**, then sign in with the right account when prompted.
5. Use **Manage profile settings** to change name, picture, or color.

**Switch profiles:** Profile icon → choose another profile. Edge opens a separate window for that profile.

[Microsoft: Sign in or create multiple profiles in Edge](https://support.microsoft.com/en-us/microsoft-edge/sign-in-or-create-multiple-profiles-in-microsoft-edge-7070e68a-99dd-4cb0-9023-1e8dbac60bbf)

## Good habits

* Before you enter passwords or upload files, glance at the **profile name and color** in the browser frame.
* Install work tools (for example [CyberDrain Check](../../tech-recommendations/software/web-browsers-and-browser-extensions-for-nonprofits.md)) in the **Work** profile; keep personal extensions in **Personal**.
* On a **shared family PC**, use a separate profile per person—not one shared Windows login with everyone in the same browser profile.

If your nonprofit standardizes on Chrome with Google Workspace or Edge with Microsoft 365, see [Web Browsers & Browser Extensions for Nonprofits](../../tech-recommendations/software/web-browsers-and-browser-extensions-for-nonprofits.md).
