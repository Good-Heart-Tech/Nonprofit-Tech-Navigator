# Display Dimmer for Nonprofits

[Display Dimmer](https://displaydimmer.com/) by [Vantari Works](https://displaydimmer.com/) is a free Windows 10/11 app for adjusting brightness and contrast on built-in screens and external monitors. It supports hardware brightness (DDC/CI) where your monitor allows it, with a software dimming fallback when it does not.

The free tier covers everyday brightness control. **Display Dimmer Pro** (one-time upgrade, no subscription) adds more schedules and app rules, per-display automation, presets, color temperature control, and command-line tools for IT.

## Complimentary Pro for nonprofits

Vantari Works offers **complimentary Display Dimmer Pro** for eligible nonprofit organizations. Each request is reviewed individually; approval and license keys are not automatic.

* [Request complimentary Pro for your nonprofit](https://displaydimmer.com/nonprofits)
* [Install from Microsoft Store](https://apps.microsoft.com/detail/9NBWHFCLN6CM) (product ID `9NBWHFCLN6CM`)
* [Pro activation help](https://displaydimmer.com/pro-activation) (license key from email after approval)

Good Heart Tech partners who need help deploying Display Dimmer on managed PCs can open a support ticket.
